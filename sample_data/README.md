# Vakyam (वाक्यम्) — Clinical & Engineering Benchmark Sample Data Suite

This directory contains **7 comprehensive empirical, simulation, and clinical benchmark datasets (`1.38 MB` total, `2,055+` structured records)** used to validate Vakyam's real-time computer vision gaze pipeline, IMU tremor stabilization, single-switch blink discrimination, on-device **Gemma 4 E2B (`LiteRT-LM`)** trilingual sentence expansion, **Sherpa-ONNX Whisper (`int8`)** offline caregiver speech recognition, and 5 bedside hardware sensor safeguards.
